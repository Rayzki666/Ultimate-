取景教练

打开取景框，它会一直盯着看：机身歪没歪、镜头是俯是仰、光从哪边来、 她在画面里站得对不对、画面下沿有没有正好切在她的关节上。

一次只说一件事，而且可以念出来——你的眼睛应该在她身上，不是在屏幕上。

画面只在你手机里处理，不上传任何地方。

这个页面在看什么
  • 认人——点开之后会实时找出她的身体关键点，构图、头顶留白、 远近、以及画面下沿有没有切在脚踝或膝盖上全部自动判断，不用再点屏幕。 模型第一次要下载约 17MB，之后就存在本机了。没点开也能用，点一下画面里她头的位置即可。
  • 语音——把当前这条提示念出来，这样你可以一直看着她。
  • 绿灯——所有项都过了，画面四周会亮一圈绿边并震一下，那就是可以按的时刻。
  • 水平——机身左右歪了几度。地平线歪 2° 以上一眼就能看出来。
  • 俯仰——镜头是朝下还是朝上。拍脸和半身略微俯拍最好看；拍全身要把手机放低。
  • 光——顺光 / 侧光 / 逆光，以及过曝欠曝。逆光不是不能拍，是要知道自己在逆光。
  • 构图框——把她放在竖线上，别放正中间；头顶别留太多空；虚线是关节切割警戒带，画面下沿别正好切在膝盖、脚踝、手腕上。

拍摄配方

先选你现在在哪儿。每张卡是一套能直接照做的动作。

她的说明书

与其猜，不如让她自己说。这份问卷是给她填的，三分钟。

AI 点评（可选）

填入你自己的 Anthropic API Key 就能用 Claude 看照片给意见。Key 只存在这台设备的浏览器里， 请求直接从你手机发到 Anthropic，不经过任何中间服务器。不填也不影响前面所有功能。

关于与数据

「好好拍」是一个纯前端网页应用，没有服务器、没有账号、不收集任何数据。 问卷答案和偏好档案存在你手机浏览器的本地存储里。清除浏览器数据会一并清掉。
